# rssradar

Трендвотчинг ниши по RSS-фидам для Claude Code: недельный дайджест в Telegram
(о чём писали + 2–3 горячие темы, которые всплыли в нескольких источниках) +
дешёвый «пульс» всплесков объёма между дайджестами. Плюс разовая визуальная
карта трендов в браузере. В каждой строке отчёта — ссылка на статью.

## Как это работает

- Данные — из открытых **RSS/Atom-фидов** (`feedparser`), бесплатно, без API,
  токенов и лимитов источника. Всё хранится локально в SQLite.
- Источники задаются вручную по URL или подбираются по теме (Claude находит
  и валидирует фиды).
- «Горячее» в недельном дайджесте выделяет **Claude** (headless). Пульс —
  чистая арифметика частот (термин вырос над своей базовой линией и попал
  в несколько источников), с лемматизацией русских словоформ.
- Отчёты приходят в Telegram через вашего собственного бота.

## Установка

1. Нужен [Claude Code](https://claude.com/claude-code) и Python 3.9+.
2. Склонируйте репо в папку скиллов:
   `git clone <repo> ~/.claude/skills/rssradar && pip install -r ~/.claude/skills/rssradar/requirements.txt`
3. Откройте Claude Code и скажите: **«настрой RSS-мониторинг»** — дальше он
   сам проведёт: источники, Telegram-бот, первый сбор, расписание.

## Команды после настройки

«сделай дайджест по RSS», «проверь пульс», «покажи карту трендов»,
«найди фиды по теме X», «добавь фид URL», «выключи автоматику».

## Стоимость

- Данные RSS — бесплатно.
- Claude: недельный дайджест и карта запускают headless Claude и тратят лимиты
  вашей подписки. Пульс и сбор данных Claude не зовут.

## Дисклеймер

rssradar читает только публичные RSS/Atom-фиды, которые сайты отдают сами —
никакого скрейпинга закрытого контента. Проект не аффилирован с источниками.
